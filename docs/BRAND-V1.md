# AgentSam Brand - public plugin v1

## Promise

Understand, organize, refine, and maintain a brand using authorized real-world evidence from websites, content, and brand assets.

## V1 scope

Read-first:
- resolve authorized brand context
- inspect brand
- list/inspect assets
- find usage
- draft BrandContract
- evaluate consistency
- build a non-destructive plan

## Deferred

- destructive deletion
- arbitrary shell/filesystem
- raw database access
- generic storage browsing
- autonomous publishing
- unrestricted third-party API execution

## Permission progression

Observe -> Prepare -> Apply -> Publish

V1 begins at Observe.

## Initial skills

- brand-audit
- brand-definition
- brand-consistency-review
- brand-asset-review
- brand-planning
