# Remote Desktop Commander connection

This is a third-party remote MCP integration. It does not grant device access until the user completes the provider's OAuth authorization. Use only devices and locations the connected account exposes.

Read-only operations may inspect authorized files, directories, metadata, search results, and existing process output. File writes, moves, directory creation, configuration changes, process starts, process interaction, termination, and shutdown are state-changing actions and require explicit user approval. Before any such action, state the target and intended effect. Never broaden the authorized device or filesystem scope.
