# Sales workflows

Use this pack to complete sales work from verified public evidence, user-provided context, and tools connected to the current AgentSam workspace. Start with sales.get_context to see which business sources are connected, then load the most relevant workflow with sales.get_workflow.

Always distinguish verified facts, user-provided claims, hypotheses, and unknowns. Include source dates for material claims. Never invent contacts, deal values, pipeline totals, buying intent, or outcomes. This plugin does not provide CRM write tools. Do not send messages, change records, or create tasks without a separately authorized tool and explicit user approval.
